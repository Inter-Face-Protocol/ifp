# IFP Drafts

Staging area for proposed IFPs that have not yet been assigned numbers and added to the main series.

The current editorial posture is to publish new proposals directly into the numbered series at `Status: Draft` rather than holding them here, since every existing IFP is also still in Draft status — there is no stable canon yet to protect. This directory remains as a convention for any future case where staging makes sense (a proposal too early to commit to a number, or a multi-document set being prepared together).
